# ДМТФК+ — автоматизація документообігу заступника директора з академічних питань

Десктопний застосунок (Python + CustomTkinter + PostgreSQL) для:
- імпорту списків студентів і викладачів із наказів (.doc/.docx);
- розпізнавання наказів про подяки та догани з багаторівневим нарахуванням балів;
- окремого обліку подяк викладачам (без нарахування балів);
- ведення рейтингової системи студентів з історією нарахувань та експортом у Excel.

## Архітектура

```
app.py                       — головне вікно, вкладки, діалоги налаштувань
config.py                    — завантаження/збереження налаштувань (БД, рівні балів)
database.py                  — шар доступу до PostgreSQL (нормалізована схема) + резервні копії
matching.py                  — зіставлення студента/викладача з наказу з базою даних
scoring.py                   — обчислення балів за нарахованими подяками
export.py                    — експорт рейтингу/списку групи/подяк викладачів у .xlsx
parsers/doc_io.py            — уніфіковане відкриття .doc/.docx
parsers/students_parser.py   — парсинг списків студентів
parsers/reward_parser.py     — парсинг наказів про подяки та догани
parsers/teachers_parser.py   — парсинг списків викладачів
tests/                       — модульні тести для парсингу, зіставлення та експорту
```

### Схема бази даних

```
groups (id, name, study_year, curator)
students (id, full_name, group_id → groups.id, funding, note)
orders (id, order_number, order_date, event_title, level_type, default_points, points_display, source_filename, source_file)
achievements (id, student_id → students.id, order_id → orders.id, points_awarded, commendation_type)
teachers (id, full_name)
teacher_rewards (id, teacher_id → teachers.id, order_id → orders.id)
```

Рейтинг рахується одним запитом з `JOIN` + `GROUP BY`. Один наказ може
містити кілька секцій (§) з різними рівнями подяки — тоді студент отримує
кілька записів у `achievements` (по одному на секцію), а рейтинг показує
індивідуальний розклад балів, наприклад «№273 (0.5+2+1)».

## Встановлення

```bash
pip install -r requirements.txt
python app.py
```

При першому запуску відкрийте **Налаштування** й вкажіть параметри
підключення до PostgreSQL. Пароль зберігається локально у файлі профілю
користувача — для спільного комп'ютера краще не зберігати пароль і
вводити його щоразу.

## Збірка .exe (Windows)

```bash
python -m pip install -r requirements.txt
python -m pip install pyinstaller
python -m PyInstaller --noconfirm Aktiv_plus.spec
```

Готовий файл з'явиться в `dist\`. PostgreSQL усе одно має бути доступний
(локально або в мережі) — параметри підключення задаються в **Налаштування**.

## Відомі обмеження

- **Зіставлення імен** використовує коефіцієнт подібності рядків
  (`difflib`), а не морфологічний аналізатор — прізвища у непрямих
  відмінках розпізнаються гірше, ніж у називному.
- **Пароль до БД** зберігається у відкритому файлі профілю користувача.
- **Формат .doc** читається лише на Windows через MS Word (`pywin32`).
  На інших ОС файл потрібно попередньо зберегти як `.docx`.
- Парсинг наказів побудований на регулярних виразах під типовий формат
  документів коледжу; суттєво інша структура може вимагати коригування.
